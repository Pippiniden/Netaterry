# ノベルメモ

小説のネタ出し・キャラクターシート作成のための、軽量なアウトライナー型メモアプリです。
GitHub Pages だけで動く静的サイト（ビルド不要）で、ホーム画面に追加して PWA として使えます。

- データは端末内（IndexedDB）に即時保存。オフラインでも起動・編集できます
- Google ドライブのアプリ専用領域（appDataFolder）と同期し、複数端末でデータを引き継げます
- テキストのみ・外部ライブラリなし（Google ログイン用スクリプトのみ、ログイン時に読み込み）

## 公開手順（GitHub Pages）

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロードします
   （`index.html` がリポジトリ直下に来るように）。
2. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存します。
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

この時点で、同期以外のすべての機能が使えます。

## Google ドライブ同期の設定（任意）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成します。
2. **APIとサービス → ライブラリ** で「Google Drive API」を有効にします。
3. **APIとサービス → OAuth 同意画面** を設定します。
   - ユーザーの種類：外部
   - スコープに `.../auth/drive.appdata` を追加
   - 公開ステータスが「テスト」の間は、**テストユーザー**に自分の Google アカウントを追加してください
     （テスト中は約7日ごとに再同意が必要になることがあります。気になる場合は「本番環境」に公開します。
     `drive.appdata` は機密性の高いスコープではないため、通常は審査なしで公開できます）
4. **APIとサービス → 認証情報 → 認証情報を作成 → OAuth クライアント ID** を選び、
   - アプリケーションの種類：ウェブアプリケーション
   - 承認済みの JavaScript 生成元：`https://<ユーザー名>.github.io`（末尾のスラッシュやリポジトリ名は不要）
5. 表示されたクライアント ID を `config.js` の `GOOGLE_CLIENT_ID` に貼り付けて、リポジトリに反映します。

アプリ右上の「ローカル」ボタン（またはメニュー →「Googleでログイン」）からログインすると同期が始まります。

### 同期のしくみ

- 編集は常に端末内に保存され、最後の編集から数秒後（設定で変更可）・「同期」ボタン・アプリを開いた時／前面に戻った時に同期します
- まずドライブ上のファイルの更新日時だけを確認し、変化がなければ何も送受信しません
- 両方で変更があった場合は、ノード単位で新しい方を採用してマージします（別々のノードの編集は両方残ります）
- アップロード直前に更新日時を再確認し、他の端末が先に更新していたらマージし直します
- 削除は「削除フラグ」として同期し、保持期間（既定30日）を過ぎたものは同期時に完全削除されます
- ログインの有効期限は約1時間です。切れると「再ログイン」表示になり、押すと未同期の変更がそのまま同期されます
  （ブラウザのポップアップブロックを避けるため、自動では再ログインしません）

## アプリを更新するとき

`sw.js` の `VERSION`（例 `v1.0.0` → `v1.0.1`）を上げてからアップロードしてください。
開いている端末に「更新があります（再読み込み）」が表示され、押したときだけ新しい版に切り替わります。

ファイルを追加した場合は `sw.js` の `ASSETS` にも追記してください。

## ファイル構成

```
index.html              画面の骨組み
style.css               スタイル
config.js               Google クライアントID
sw.js                   Service Worker（オフライン対応）
manifest.webmanifest    PWA 設定
icons/                  アイコン
js/
  app.js                起動・画面全体の制御
  store.js              状態管理・Undo/Redo・ノード操作
  db.js                 IndexedDB
  merge.js              データ移行・ノード単位マージ・ゴミ箱の掃除
  sync.js / drive.js    Google ドライブ同期・ログイン
  search.js             検索・置換
  tags.js               タグの正規化・集計
  markdown.js           エクスポート整形・Markdown 相互変換
  util.js               共通処理
  ui/                   画面部品（ツリー・エディタ・検索・閲覧・各種ダイアログ）
tests/unit.test.mjs     ロジックのテスト（node --test tests/unit.test.mjs）
```

## データの保存形式

ドライブ上の `novelmemo.json`（バックアップ JSON も同じ形式）:

```json
{ "schemaVersion": 1, "nodes": [ ... ], "templates": [ ... ] }
```

表示設定・テーマ・絞り込み状態・検索履歴は端末ごとの保存で、同期しません（設定画面から設定ファイルとして書き出し・読み込みできます）。

## 注意

- iPhone / iPad の Safari は、しばらく開かなかったサイトのデータを削除することがあります。ホーム画面に追加して使い、ときどきメニューの「バックアップを保存」をしておくと安心です。
- 閲覧モードの縦書き・ページめくりはブラウザのレイアウト機能を使っています。表示が崩れる端末では「スクロール」表示に切り替えてください。
