# Netaterry

小説のネタ出し・キャラクターシート作成を、いつでもどこでも軽く行うための個人用メモアプリです。
大手アプリのような多機能・装飾重視ではなく、シンプルで軽量なテキストベースを目指しています。
操作感は、アウトラインプロセッサ「NanaTerry」（ノード単位でテキストを分割・ツリー管理する編集感覚）を参考にしています。

ホーム画面に追加して PWA として使えます。オフラインでも起動・編集できます。
モバイル回線での利用を想定し、画像などは扱わずテキストのみで完結します。

初めて開いたときは、操作を試しながら読める説明ツリーと『オデュッセイア』を題材にしたサンプルが、作品「使い方とサンプル」として入っています。読み終えたら自由に消してかまいません。

作品ごとにデータを分けて持てます。編集内容はこの端末（ブラウザ）の中に自動で保存されます。Google にログインすると、マイドライブの「Netaterry」フォルダに作品ごとのファイルとして保存され、複数の端末で同期できます（あらかじめ運営者側の設定が必要です）。

---

## 機能一覧

### データの持ち方

ノードはマークダウンの見出し記号を使わず、親子関係（`parentId`）で階層を持ちます。閲覧モードでの見出し風の見た目は、アプリが階層の深さから自動生成しているだけです。

ノード1件が持つ情報：

| 項目 | 内容 |
| --- | --- |
| タイトル | プレーンテキスト |
| 本文 | プレーンテキスト |
| サイドメモ | 本文とは別枠の、ワンタッチで呼び出せる作業用メモ |
| タグ | フリーテキストの配列。固定のノード種別は持たず、分類はすべてタグに任せる |
| 開閉状態 | ツリー上での表示・非表示 |

ノードは「作品」に属します。作品ごとに持つもの・全作品で共通のものは次のとおりです。

| 作品ごと | 全作品で共通 |
| --- | --- |
| ノードツリー、タグ、共通メモ（どのノードからでも見られるメモ）、ゴミ箱、元に戻すの履歴 | テンプレート、表示設定 |

### 作品

- 上部の作品名を押すと作品の一覧が開き、切り替え・新規作成ができます
- 一覧の「…」から、名前の変更・複製・ファイルに保存・削除
- 「ファイルに保存」した作品は「ファイルから読み込む」で、新しい作品として追加／今の作品にマージ／今の作品を置き換え、のいずれかで取り込めます
- 最後に開いていた作品を次回も開きます

### 保存・同期（Google ドライブ）

- 編集内容はまず端末内（IndexedDB）へ即時保存されます。オフラインでも問題なく起動・編集できます
- Service Worker がアプリ本体をキャッシュするため、圏外でも起動できます
- Google ドライブに同期すると、複数端末でデータを引き継げます
  - 保存先はマイドライブの「Netaterry」フォルダです。作品ごとに `作品名.json`、テンプレートは `テンプレート.json` を置きます
  - ドライブの画面から見たりダウンロードしたりできます。ファイル名を変えたり別のフォルダへ動かしたりしても同期は続きます（ファイル名は作品名に戻ります）
  - ドライブでファイルを削除すると、その作品は各端末からも外れます（ドライブのゴミ箱から戻せます）
  - アプリで作品を削除すると、そのファイルはドライブのゴミ箱へ移ります
  - ほかの作品は一覧にだけ出し、中身は開いたときに取得します
- 同期タイミング：編集後のデバウン（数秒後・設定で変更可）、手動の同期ボタン、アプリを開いた時・前面に戻った時
- 先にドライブ側の更新日時だけを確認し、変化がなければ何も送受信しません
- 双方に変更がある場合は、ノード・テンプレート・共通メモ・作品名の単位で新しい方を採用してマージします（別々のノードの編集は両方残ります。同じノードを両端末で編集した場合のみ、古い方が失われます）
- アップロード直前に更新日時を再確認し、他の端末が先に更新していたらマージし直してから送信します
- 削除は物理削除せずフラグを立てて同期し（トゥームストーン）、保持期間（既定30日、設定で変更可）を過ぎたものは同期時に完全削除されます
- ブラウザによる自動データ削除を防ぐため、起動時に永続化を要求します（iOS Safari 対策として、ホーム画面への追加を推奨します）

### ログイン

- Google Identity Services のトークンモデル（クライアントサイド OAuth）を使用し、サーバーなしで動作します
- スコープは `drive.file`（このアプリが作ったファイルだけを読み書きできる）に限定。ほかのドライブのファイルは読めません
- v1.3 以前に同期していた端末では、初回だけ旧保存先（`drive.appdata`、ドライブの画面に出ないアプリ専用領域）も読み、そのデータを作品「最初の作品」に取り込みます
- アクセストークンの有効期限は約1時間。切れると画面に「未同期」表示が出て、編集内容はそのままローカルに残ります
- 「再ログイン」ボタン（ユーザー操作）を押すとログインし直し、未同期の変更がそのまま同期されます（ポップアップブロック対策のため自動では再ログインしません）
- 未ログインでも、この端末内ですべての機能を使えます

### ノード操作

| 操作 | 内容 |
| --- | --- |
| 追加 | 「下に兄弟ノード追加」「子ノード追加」 |
| 削除 | ゴミ箱へ移動（子孫もまとめて） |
| ゴミ箱 | 削除済みノードの一覧・個別復元・個別の完全削除・空にする |
| 自動クリーン | 保持期間を過ぎたものを同期時に完全削除 |
| 移動 | 「上へ」「下へ」「階層を上げる／下げる」。PCではドラッグ＆ドロップも可 |
| 開閉 | ツリー上で子ノードの表示・非表示を切り替え |
| 複製 | 選択ノード（＋子孫）を新しい ID でコピー |
| 元に戻す | セッション内の Undo / Redo（同期はしない） |

PC のキーボード操作：↑↓ 選択、←→ 開閉、Tab / Shift+Tab で階層、Alt+↑↓ で移動、Ctrl(⌘)+Enter で兄弟追加、Enter で編集、Delete で削除。

### 編集モード

- ノード単位のプレーンテキスト入力。装飾記号を意識せずに書けます
- オートインデント（改行時に前の行の字下げを引き継ぐ）を ON/OFF できます
- 特殊文字の可視化：改行・タブ・全角スペース・行末の余分な空白・EOF を記号化して確認できる、読み取り専用の点検ビュー（通常の編集は通常のテキスト入力のまま）
- テンプレート呼び出し、サイドメモ編集、タグ編集をツールバーから行えます

### タグ機能

- タイトル直下のチップ欄に入力し、Enter または「,」「、」で確定
- IME の変換確定の Enter ではタグが確定しないよう配慮
- タグ内の空白は許可（例：「主人公 候補」）。前後の空白のみ除去
- 入力中に既存タグを候補表示（部分一致・使用回数順）
- 全角/半角・大文字/小文字は同一視して重複登録を防止
- ひらがな/カタカナの同一視（設定で ON/OFF、既定 OFF）。ON にすると表記ゆれのタグを候補の先頭に出して統合を促します
- 階層タグ：「キャラ/主人公」のように「/」で区切ると、「キャラ」で絞り込んだときに配下もまとめて拾えます
- タグ絞り込みバー：複数タグを選択し、AND / OR を切り替え。ツリー表示（該当ノード＋祖先を保持）とフラット一覧を切り替え可能。「子孫も含める」も選べます
- タグ管理画面：全タグの一覧・使用ノード数、名前の一括変更、統合、削除

### 検索機能

すべて端末内で行われ、通信は発生しません。

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| `語1 語2` | すべて含む（AND） | `王都 騎士` |
| `-語` | 含まないものに絞る | `騎士 -団長` |
| `"語 句"` | 空白を含む語句そのまま | `"黒い 剣"` |
| `tag:タグ名` | タグで絞る（階層タグは前方一致） | `tag:キャラ` |
| `in:title` / `in:body` / `in:note` | 検索する場所を限定 | `in:title 王都` |

- 検索対象：タイトル・本文・タグ（既定 ON）、サイドメモ・ゴミ箱内（オプションで ON）
- 「このノード以下を検索」で範囲を限定、タグ絞り込みとの併用も可能
- 全角/半角・大文字小文字は同一視、ひらがな/カタカナの同一視も切り替え可能
- 結果はタイトル・階層の経路・一致箇所の抜粋・一致数を表示し、タップでそのノードを開いて一致箇所へジャンプ（前へ／次へで移動）
- 直近10件の検索語を端末内に履歴保持
- PC では Ctrl+F（Mac は ⌘+F）で検索欄にフォーカス

**一括置換**：検索結果から置換後の文字列を入力し、対象を1件ずつ除外しながらプレビュー確認。実行後は Undo で一括して戻せます。

### 閲覧モード（ビューモード）

- ノードの深さに応じて見出しサイズ・インデントを自動生成（見出しはノードのタイトルから付くので、本文に `#` を書く必要はありません）
- 本文は「1行＝1段落」として表示します（小説の改行・字下げをそのまま生かすため、Markdown のような行の連結はしません）
- 本文とタイトルでは、次の記法が使えます（編集画面では記法のまま表示され、閲覧モードでだけ変換されます）

| 記法 | 表示 | 備考 |
| --- | --- | --- |
| `｜魔導書《グリモワール》` / `\|魔導書《グリモワール》` | ルビ | 小説家になろう・カクヨムと同じ書き方 |
| `王都《おうと》` | ルビ | 漢字の直後なら `｜` を省略できる（直前の漢字の連続が親文字） |
| `｜《括弧》` | 《括弧》 | 《 をそのまま表示 |
| `《《決して》》` | 傍点 | カクヨム式。横書きは「•」、縦書きは「﹅」 |
| `---` / `___` | 区切り線 | 行に記号だけを書く |
| `* * *` / `***` / `＊＊＊` / `◇◇◇` / `◆◇◆` など | 場面転換 | 記号を行の中央に表示（`* * *` は「＊　＊　＊」） |
| `# 見出し` 〜 `###### 見出し` | 本文中の小見出し | `#` の後に空白が必要（`#タグ` は変換しない） |
| `**太字**` / `__太字__` | 太字 | |
| `*斜体*` / `_斜体_` | 斜体 | 縦書きでは傍線で表示 |
| `~~取り消し~~` | 取り消し線 | |
| `` `コード` `` / ```` ``` ```` で囲んだ行 | 等幅 | 中の記法は変換しない |
| `[文字](https://…)` | リンク | http / https のみ |
| `- 項目` / `* 項目` / `+ 項目` | 箇条書き | 行頭の字下げで入れ子 |
| `1. 項目` | 番号付き | |
| `> 引用` | 引用 | 横書きは左の線、縦書きは字下げ |
| `\*` など | 記号そのまま | 記号の前に `\` |

- 縦書きでは 2 桁までの半角数字と `!!` `!?` `?!` `??` を縦中横で表示します
- 表（テーブル）・画像・HTML タグには対応していません（テキストのみで完結させるため）
- 縦書き・横書きのページめくりは、どちらもブラウザの段組み機能で「1段＝1ページ」にしています。ルビや傍点、見出しで行の高さが変わっても、行の途中でページが切れることはありません
- 開いているノードだけを描画する遅延レンダリング
- 縦書き表示（`writing-mode: vertical-rl`）。編集モードは常に横書きです
  - 縦中横で2桁までの半角数字を横並びに
- ページめくり表示：横書き・縦書き両対応。画面の左右タップ・スワイプ・矢印キーでめくり、中央タップでメニュー表示
  - 現在ページ／総ページを表示、フォントサイズ変更・回転・余白変更の前後で表示位置を保持
  - 「最上位ノードごとに改ページ」を設定可能
  - 表示が崩れる・重い端末では通常のスクロール表示に切り替え可能
- 表示のカスタマイズ（後述）は編集用・閲覧用で別々に設定できます

### テンプレート機能

- テンプレートは全作品で共通です
- テンプレート管理画面で一覧・新規作成・編集・削除
- 1件ずつ「書き出す」でファイル（`テンプレート名.template.json`）にでき、「すべて書き出す」でまとめて保存できます。「ファイルから読み込む」で追加します（同じ内容のものは飛ばし、名前が重なるものは「（読み込み）」を付けて追加）
- 呼び出すと本文を丸ごと置き換えます（本文が空でない場合は確認ダイアログ、置き換え後も Undo で戻せます）
- 本文中の `{{変数名}}` を自動検出し、呼び出し時に入力ダイアログを生成（同じ変数名は一括反映、未入力時は残す／削除するを選択可）
- テンプレートに既定タグを持たせ、呼び出し時にノードへ自動付与（例：キャラクターシート → 「キャラ」）

### エクスポート・バックアップ

**エクスポート**（読み物としての書き出し。常にコピー生成で元データは変更しません）

- 対象範囲：選択ノード単位／選択ノード＋子孫／作品全体
- 形式：プレーンテキスト（記号なし）、Markdown（階層に応じて `#`〜`######`、7階層目以降は太字表記）、キャラクターシート用固定テンプレ
- サイドメモを含めるかどうかを選択（既定 OFF）。「毎回確認」か「設定で固定」かを設定画面で切り替え可能
- 削除済みノードはエクスポート対象外

**バックアップ／インポート**（データの保険。アプリ内部形式のまま）

- 「バックアップを保存」ですべての作品とテンプレートを1つの JSON にまとめてダウンロード
- 「ファイルから読み込む」は、中身を見て処理を変えます
  - バックアップ：同じ作品はマージ、または「バックアップの状態に戻す」（中身を置き換え、ない分はゴミ箱へ）。この端末にない作品は追加
  - 作品ファイル・v1.3 以前のバックアップ：新しい作品として追加／今の作品にマージ／今の作品を置き換え
  - テンプレートファイル：テンプレートに追加
- 今の作品へのマージ・置き換えは「元に戻す」で戻せます

**JSON ↔ Markdown 相互変換**（外部エディタでの読み書き用）

- 通常の Markdown ビューアでも読める形式で、ノード情報は HTML コメント（`<!-- node {...} -->`）に埋め込みます
- 見出しの深さ＝階層、7階層目以降は `######` を使い `depth` をコメントに記録
- 読み込み時はプレビュー（ノード数・階層・警告一覧）を表示し、バックアップ取得を推奨
- 反映方法：新しい子ツリーとして追加（既定・既存データを変えない）／id が一致するノードを更新／全体を置き換え
- 見出しレベルの飛び・id の重複・埋め込みコメントの欠落などは警告を表示します
- 普通の Markdown（往復用の書式なし）を読み込むと、見出しの深さから階層を推定してすべて新規ノードとして作成します

### 表示のカスタマイズ

- マージン（上下左右）、背景色、文字色、選択色を自由に設定
- 「編集用テーマ」と「閲覧用テーマ」を別々に設定（編集中は目に優しい配色、閲覧時は紙っぽい雰囲気、など）
- 表示設定は端末ごとのローカル保存で、Google ドライブには同期しません
- 設定一式を小さな JSON ファイルとして書き出し・読み込みでき、別端末に同じ見た目を持ち込めます（余白など画面幅に依存する項目は適用する／しないを選択可）

### サイドメモ機能

- 本文とは別枠のメモを、ワンタッチのポップアップ／スライドパネルで編集
- 2つのタブで切り替えて使います
  - **このノード**：開いているノードだけのメモ
  - **共通**：その作品のどのノードを開いていても同じ内容が表示されるメモ（用語集・登場人物の早見表・執筆中の ToDo など、作品全体に関わるメモ向け）。作品ごとに別々です
- 内容があるタブには印が付きます。最後に使ったタブを覚えています
- 共通メモはノードを選んでいなくても、メニューの「共通メモ」から開けます
- 通常の閲覧モードには表示されません（作業用のメモという位置づけ）
- どちらも編集すると同期対象になります。共通メモも Undo / Redo の対象で、バックアップ JSON に含まれます（Markdown 変換の対象外）

---

## 注意

- iPhone / iPad の Safari は、しばらく開かなかったサイトのデータを削除することがあります。ホーム画面に追加して使い、ときどきメニューの「バックアップを保存」をしておくと安心です。
- 閲覧モードの縦書き・ページめくりはブラウザのレイアウト機能を使っています。表示が崩れる端末では「スクロール」表示に切り替えてください。
